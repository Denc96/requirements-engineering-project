# Requirement surgery overview/work

## Problem - there is no clarification on what user and in what way would it be user-friendly.
## Q. - What user are we talking about and what would you like that would make it user friendly?
## Info - The information that is missing is that we don't know the user and we don't know what way they want to make it user friendly.

## Problem - no clarification on what users would be notified.
## Q. - What users would you like to be notified?

# Develop functional requirements

## 1. "The technician needs to know whether equipment is available before confirming a booking."
## Who - technician.
## What - needs to know whether equipment is available before confirming a booking
## when - when a booking is about to take place.
## why -  so the technician can know what equipment is available before the booking takes place.
## how will we know - We can verify it when the system is able to show the technician that the piece of equipment is available before the booking is confirmed.
